# AutoHunter Russia — Telegram MVP

Первая рабочая основа Telegram-бота: добавление объявлений в отслеживание, список избранного, удаление из списка и уведомления об изменении цены.

## Важно про источники объявлений

Бот не подключён автоматически к Avito, Auto.ru или Drom: для этого нужен доступный и разрешённый API/партнёрский фид либо отдельное согласованное подключение. Не используйте обход авторизации, CAPTCHA, ограничений доступа или правил площадок.

Сейчас модуль `autohunter/feed.py` принимает JSON от совместимого источника. Если `FEED_URL` не задан, ручное отслеживание и список работают, но автоматическая проверка изменения цены не выполняется.

## Запуск

1. Установите Python 3.11 или новее.
2. Создайте Telegram-бота через официального `@BotFather` и скопируйте токен.
3. Распакуйте архив и откройте папку проекта.
4. Установите зависимости:

   ```bash
   python -m venv .venv
   # Windows: .venv\\Scripts\\activate
   # macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```

5. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.
6. Запустите:

   ```bash
   python -m autohunter.bot
   ```

## Команды Telegram

- `/start` — меню и инструкции
- `/watch Ссылка | Название | Цена` — добавить объявление
- `/list` — показать отслеживаемые объявления
- `/unwatch ID` — перестать следить за объявлением
- `/game` — мини-игра «Угадай стоимость»

Пример:
`/watch https://example.ru/car/123 | Kia Rio | 850000`

## Формат фида

`FEED_URL` должен возвращать JSON-массив:

```json
[
  {
    "title": "Kia Rio",
    "price": 850000,
    "url": "https://provider.example/listing/123",
    "city": "Kazan",
    "year": 2018,
    "mileage_km": 95000,
    "market_price": 1000000
  }
]
```

Проверка выполняется с интервалом `POLL_SECONDS` (минимум 60 секунд). Фид должен содержать актуальную цену тех же URL, которые добавлены в отслеживание.

## Следующие этапы

График и рыночная оценка требуют накопленных исторических данных и источника сопоставимых объявлений. Не следует считать разницу с произвольной ценой продавца гарантированной прибылью.


## Шаблоны продавцу и мини-игра

Готовые тексты для первого контакта, вопросов о состоянии, торга и осмотра находятся в `MESSAGES_RU.md`.

Команда `/game` запускает мини-игру: бот показывает учебный пример автомобиля, игрок угадывает цену, после чего бот раскрывает демонстрационный ориентир и разницу. Сейчас цены игры заданы как учебные примеры. Для настоящей оценки нужно подключить актуальный источник сопоставимых объявлений и учитывать регион, комплектацию, состояние, историю ДТП и юридические ограничения.


## Подготовленные интеграции источников

### Дром (экспериментальный адаптер)
В `autohunter/providers/drom.py` подготовлен клиент поиска по документированному пути `/v1.2/bulls/search`. Поддерживаются параметры `cityId`, `regionId`, `page`. Адаптер выключен по умолчанию (`DROM_ENABLED=0`): перед включением нужно подтвердить доступ и проверить фактический JSON-ответ. Документация Дрома описывает поиск по городу/региону и другие фильтры, но конкретный формат ответа в адаптере пока считается предварительным.

Для теста после подтверждения доступа:
1. В `.env` выставить `DROM_ENABLED=1`.
2. Указать `DROM_CITY_ID` или `DROM_REGION_ID`.
3. При необходимости задать `DROM_SIGN`, если это требуется выданным доступом.
4. Запустить бота и проверить журнал ошибок и нормализацию карточек.

### Авто.ру
В `.env` предусмотрен `AUTORU_TOKEN`, но адаптер не включён: официальная документация указывает, что API требует токен, который нужно запросить у менеджера Авто.ру. Доступные методы включают оценку стоимости и справочные данные; не следует считать, что любой токен даёт доступ к поиску всех публичных объявлений.

### Авито
Подключение оставлено через `FEED_URL` — URL разрешённого партнёрского/поставщицкого фида, возвращающего JSON по формату выше. Не используйте автоматизацию, обходящую авторизацию, CAPTCHA или ограничения площадки.

**Ограничение текущей версии:** это подготовленные адаптеры, а не подтверждённое живое подключение. До получения ключа/разрешённого фида бот не сможет самостоятельно искать все новые объявления на площадках. После первого тестового ответа поставщика нужно будет при необходимости уточнить соответствие полей.

## Безопасная настройка Telegram-токена

1. Если токен уже отправлялся в чат или кому-либо ещё, сначала отзови его через официальный **@BotFather**: `/revoke` → выбери своего бота. Старый токен после этого перестанет работать.
2. В папке проекта скопируй `.env.example` в файл `.env`.
3. Открой `.env` и замени значение `BOT_TOKEN` на новый токен, полученный у BotFather. Не вставляй токен в исходники, сообщения или публичные репозитории.
4. Установи зависимости и запусти бота:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\\Scripts\\activate
   # macOS/Linux:
   source .venv/bin/activate

   pip install -r requirements.txt
   python -m autohunter.bot
   ```

Файл `.env` уже добавлен в `.gitignore` и не должен попадать в архивы, Git или переписку. В архив включён только безопасный шаблон `.env.example`.

**Важно:** после запуска на компьютере бот работает, пока запущен процесс и компьютер подключён к интернету. Для постоянной работы потребуется настроить запуск на сервере. Мониторинг цен начнёт присылать изменения только после подключения рабочего источника объявлений; сам Telegram-токен не даёт доступ к каталогам автомобилей.
